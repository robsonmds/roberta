# Definition of Done — Roberta

O Orchestrator adapta ao nível de risco e **declara explicitamente** o que não se aplica e por quê.

- [ ] Requisito atendido e rastreável até a story
- [ ] Arquitetura/documentação atualizada
- [ ] Código seguindo as convenções do projeto
- [ ] Testes adequados ao risco, com **evidência de execução**
- [ ] Tratamento de erros e logging (sem dado sensível)
- [ ] Observabilidade quando aplicável
- [ ] SAST + scan de dependências + scan de secrets sem HIGH/CRITICAL em aberto
- [ ] Code review por agente independente
- [ ] QA aprovado
- [ ] Adversarial review (R3/R4)
- [ ] Performance avaliada quando aplicável
- [ ] Acessibilidade verificada quando houver UI
- [ ] ADR criado para decisão de alto impacto
- [ ] CI verde (evidência)
- [ ] Migrations com rollback validado
- [ ] Rollback do release documentado
- [ ] Memória do projeto (`.roberta/`) atualizada
- [ ] Aprovação humana obtida quando exigida (§23)
